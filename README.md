# hataclip

Windows 向けのテキスト専用クリップボードピッカー。常時監視はしない。

ホストに入れるのは **Docker だけ**。Rust / Node の開発パッケージは不要。成果物は Windows の `exe` のみ。

## clone 直後のビルド

```bash
git clone <this-repo>
cd hataclip-tauri
docker compose run --rm test
docker compose run --rm windows-build
```

Windows（PowerShell 7）:

```powershell
git clone <this-repo>
cd hataclip-tauri
./scripts/test.ps1
./scripts/build-windows.ps1
```

初回はイメージの構築で時間がかかる。

`node_modules` と `.svelte-kit`、`src-tauri/target` は Docker のボリュームに置く。バインドマウント越しの書き込みが遅いため。ホスト側にこれらは増えないので、作り直したいときはボリュームを消す:

```bash
docker compose down -v
```

## 成果物

`dist/windows/hataclip.exe` と、同じフォルダの `WebView2Loader.dll` / `libgcc_s_seh-1.dll` / `libstdc++-6.dll` / `libwinpthread-1.dll`

インストーラ（`.msi` など）は出さない。

## 実行

`dist/windows` ごとコピーしてから:

```powershell
.\dist\windows\hataclip.exe
```

起動後はトレイに常駐する。ショートカットでも出す。トレイの右クリックから設定と終了。

- `Ctrl+4` 前面の選択を登録（選択が無ければクリップボード）。登録後クリップボードは元に戻る
- `Ctrl+7` ドロップダウンを表示。前回選んでいた行があればそこを選ぶ
- `Ctrl+Shift+H` 前面で選んだ `{{date}}` / `:sh dir` / `:echo 2+3` を置き換えて貼る。無ければ何もしない。一覧は出さない
- `Ctrl+Shift+1`〜`9` 一覧を出さずに、いまの並びのその番号を貼る（設定の「速貼」で on/off）
- トレイを左クリックしてもドロップダウンを表示

`Ctrl+4` と `Ctrl+7` と展開はトレイの `Settings` から変更できる。設定は `settings.json` に残る。位置とサイズもここに残る。ほかのアプリに取られているキーは登録に失敗して、元のキーに戻る。

前面アプリへ送るコピー／貼り付けは、初期値 `ctrl+c` / `ctrl+v`。プロセス名ごとに変えるときは `target_keys` に書く。`:settings` でファイルを開く。`:set paste shift+insert` は、いま前面にあるアプリの貼り付けだけ書く。

```json
"target_keys": {
  "putty": { "copy": "ctrl+insert", "paste": "shift+insert" },
  "windowsterminal": { "copy": "ctrl+shift+c", "paste": "ctrl+shift+v" }
}
```

## キー操作

一覧の中で `:help`。機能ごとなら `:help sh`。`{{date}}` などのトークンは `:help template`。

### 移動

| キー | 動き |
| --- | --- |
| `j` / `k`、`↓` / `↑` | 移動。先頭と末尾で止まる |
| `gg` / `G` | 先頭 / 末尾へ |
| `/` | 検索。IME で日本語変換してから絞る（`tokyo` では `東京` に当たらない） |
| `Ctrl+N` / `Ctrl+P` | 検索中でも移動 |
| `Tab` / `Shift+Tab` | 通常はよく使うタグで絞り込みを切り替える。検索中は一覧へ（絞りと検索欄は残る）。`#` の候補があるときはタグ補完 |
| `a` | いまの貼り付け先に記録がある行だけ。もう一度で解除 |
| `f` のあと 1 文字 | その文字で始まる行へ。`;` 次、`,` 前 |
| `Ctrl+D` / `Ctrl+U` | 半ページ下 / 上。端で止まる |
| `g` のあと `e` | 選択行を展開して全文。`{{sh:}}` はここで実行する（2秒・1000行・100KBで打ち切り）。もう一度で閉じる |
| `g` のあと `?` | 回数・貼り付け先・タグ。もう一度で閉じる。`j` / `k` で行が変わればその行の情報 |
| `Esc` / `Ctrl+[` | 検索の絞りを外す。絞りが無ければ閉じる。選択中なら選択だけ解除。ヘルプ中はヘルプだけ閉じる。`g` 待ちのときは待ちだけ解除 |

`g` / `d` / `y` / `f` / `<leader>` のあと 400ms キーが無ければ、次に押せるキーを一覧の下に出す。出る前に次のキーを押せば出さない。

### 貼り付け・コピー

| キー | 動き |
| --- | --- |
| `Enter` | 貼り付けて閉じる。次に一覧を出すとその行 |
| `Ctrl+Enter` | 貼り付けて一覧を残す（続けて貼れる） |
| `Shift+Enter` | 整形して貼り付ける |
| `1`〜`9` | その番号の行を貼り付けて閉じる |
| `Ctrl+1`〜`9` | その番号の行を貼り付けて残す |
| `g` のあと `Enter` | テンプレートも `#run` も通さず本文のまま貼る |
| `g` のあと `J` | `V` 中ならカンマでつないで貼る |
| `g` のあと `T` | `V` 中ならタブでつないで 1 行にして貼る。`V` でなければ何もしない |
| `g` のあと `>` / `:quote` | 各行先頭に `> `。すでに `>` ならそのまま。履歴は触らない |
| `g` のあと `*` / `:bullet` | 各行先頭に `* `。すでに `* ` ならそのまま |
| `:type` | `Ctrl+V` ではなく 1 文字ずつ送る。履歴のタグは触らない |
| `g.` | 直前に貼った行をもう一度。失敗したとき・`#once` で消えたあと・終了後は何もしない |
| `Ctrl+C` | 展開してクリップボードへ。`{{sh: dir}}` も実行する。履歴の本文は書き換えない |
| `gf` | URL ならブラウザ、パスなら Explorer |

`Shift+Enter` の整形は、行頭の `>` を外す、前後の空白を落とす、連続した空行を 1 つにまとめる、全体を囲む `"` `'` `「」` を外す。中のインデントは残す。

貼ったあとは、元のクリップボード（テキストのときだけ）を 200ms 後に戻す。

本文のプレースホルダは貼る直前だけ置き換わる。履歴の本文は書き換わらない。

| トークン | 中身 |
| --- | --- |
| `{{date}}` | `2026/09/20` |
| `{{time}}` | `10:54` |
| `{{date:%Y%m%d}}` / `{{date %Y%m%d}}` | chrono の strftime |
| `{{date-1d}}` / `{{date-1d:%Y%m%d}}` | 昨日。`{{date+2d}}` も可 |
| `{{clip}}` | いまのクリップボード。空なら空 |
| `{{sel}}` | 前面の選択。無ければ空 |
| `{{ask:名前}}` | 貼る前に入力。同じ名前は 1 回 |
| `{{pick: prod, stg, dev}}` | 貼る前に候補から選ぶ。`j` / `k` と Enter。Esc は中止（一覧は残す）。同じ候補は 1 回。`{{ask:}}` があるときは先に全部聞く。候補に `{{var:a}}` を書ける |
| `{{app}}` / `{{front}}` | 前面アプリのプロセス名 / ウィンドウタイトル。無ければ空 |
| `{{n}}` / `{{n:2}}` | 連番。`Ctrl+Enter` で増える。`:n 100` で初期値。閉じると初期値に戻る。`ge` や `Ctrl+C` では進まない |
| `{{uuid}}` | UUID v4 |
| `{{user}}` / `{{host}}` | ログイン名 / コンピュータ名 |
| `{{env:USERPROFILE}}` | 同名の環境変数。無ければ空 |
| `{{@foo}}` | `#alias:foo` の行の本文。一覧の並びで先の行。差し込んだ本文も展開する。同じ名前を二度辿ったら空。エイリアス側の `#run` などは見ない |
| `{{var:a}}` / `{{var a}}` | `:set a=` の値。書いたまま残して、貼るとき展開。中の `{{date}}` も展開する。値が `:sh dir` ならそのとき実行。`:set` では実行しない。`:` はエクスプローラーの名前に使えないので空白でもよい |
| `{{tag:work}}` / `{{tag work}}` | いまの一覧でタグ `work` の本文。並びどおり、改行つなぎ。差し込んだ本文も展開する。同じタグを二度辿ったら空。その行の `#run` などは見ない |
| `{{type:<Tab>}}` / `{{type <Tab>}}` | 貼る途中でキーを送る。`id{{type:<Tab>}}pass` は `id` を貼って Tab を押して `pass` を貼る。`{{type:<Ctrl+A>abc<Tab><Ctrl+A>def<Enter>}}` も可。矢印は `<Up>` `<Down>` `<Left>` `<Right>`。F キーは `<F1>`〜`<F24>`。`<Ctrl+Shift+A>` のように修飾キーを重ねられる。`<...>` の外の文字は 1 文字ずつ送る。`Tab` `Enter`/`CR` `Esc` `Space` `BS` `Del` `Home` `End` `PgUp` `PgDn` |
| `{{wait:200}}` / `{{wait 200}}` | そのあと 200ms 待つ。最大 5 秒 |
| `{{sh: コマンド}}` | `#run` 付きの行だけ実行。標準出力。失敗したら貼らない |

`#run` 付きで `{{sh:}}` が無ければ、本文全体を PowerShell として実行する。貼る前に標準出力を出して、Enter で貼る・Esc で中止。`#file` は本文をパスと見てファイル内容を貼る（`#run` が優先）。`:type` は `Ctrl+V` ではなく 1 文字ずつ送る。`#once` は貼って成功したらその行を消す。`#tsv` は展開後をタブ区切りにする（JSON 配列か 1 行 1 値。壊れそうなら貼らない。`#run` が先）。`#log:C:\notes\out.md` は前面へ貼らずファイル末尾へ追記する（`#run` があるときはその標準出力を追記）。

`:` の代わりに空白でも同じ。`{{var a}}` `{{env USERPROFILE}}` `{{date %Y%m%d}}` `{{sh echo hi}}` `{{tag work}}` `{{type <Tab>}}`。エクスプローラーの名前変更では `:` が使えない。

`Ctrl+4` と `Ctrl+7` は全体のショートカットが先に取るので、一覧内の `Ctrl+4` / `Ctrl+7` では貼れない。

### 編集・整理

| キー | 動き |
| --- | --- |
| `dd` | 削除。`p` / `P` で戻せる |
| `u` | 直前の `dd` を取り消す（1 段だけ） |
| `yy` / `Y` | ヤンク |
| `p` / `P` | ヤンクしたものを下 / 上に置く |
| `o` | 空の行を作って編集。`Esc` はその行を捨てる |
| `S` | 本文を改行で分割して複数行にする |
| `J` | `V` 中なら選んだ行を改行で 1 行にまとめる。タグは和集合。ピンはどれかにあれば残す。`S` の逆 |
| `c` | すぐ下に複製（新しい id、回数は 0）。`V` 中は範囲ごと |
| `e` | その場編集（`Ctrl+Enter` 保存、`Esc` 取り消し） |
| `E` | nvim（無ければ `$EDITOR`、それも無ければメモ帳）で編集。閉じると読み戻す |
| `t` / `T` | タグを付ける / 外す |
| `gp` | ピン留めを切り替える |
| `+` / `-` | ピンを 1 つ上 / 下へ |
| `u` / `Ctrl+R` | 一覧の変更を取り消す / やり直す |
| `.` | 直前の変更をもう一度 |
| `:` | コマンド。`Tab` / `Shift+Tab` でコマンド名を補完 |

`.` が覚えるのは `dd`・`p` / `P`・`t` / `T`・`gp`・`S`・`J`・`c`・`:s`・`:sort`・`+` / `-` だけ。移動やヤンク、貼り付けは覚えない。アプリを終了すると忘れる。

ファイルを一覧へドロップすると、パスを本文にして `#path` と `#file` を付けた行を先頭に作る。フォルダでもよい。常時監視はしない。

`:` のあと:

| コマンド | 動き |
| --- | --- |
| `:help` / `:help sh` / `:help template` | 使い方。`j` / `k` でスクロール。`{{date}}` などの一覧は `template` |
| `:sh dir` | 1 行実行して標準出力を貼る。履歴には残さない |
| `:@` | 直前の `:sh` をもう一度 |
| `:export <path>` | 履歴を Markdown に書く |
| `:import <path>` | その Markdown を読み戻す |
| `:quote` / `:bullet` | `g>` / `g*` と同じ |
| `:type` | `Ctrl+V` ではなく 1 文字ずつ送る。履歴のタグは触らない |
| `:echo 2+3` | 四則演算の結果を貼る。`*` `/` が先。`()` で変えられる。`:set a=2` の変数も使える。失敗したら貼らない |
| `:s/old/new` | 選択行の本文の `old` を全部 `new` に。正規表現は使わない |
| `:sort` | `V` 中なら選んだ行を本文の順に並べ替える。ピン・タグ・回数はそのまま。範囲の先頭の位置から置く。`.` の対象。`u` で戻せる |
| `:clear` のあと `:clear yes` | ピン留め以外を消す |
| `:dedup` のあと `:dedup yes` | 空白と改行だけ違う行を 1 つに。ピンがある方、どちらもピンなら新しい方。`u` で戻せる |
| `:map lhs rhs` | 通常モードのキーを付け替える。再帰しない。`:map <leader>* <cmd>bullet` のように書ける |
| `:unmap lhs` | 付け替えを消す |
| `:map` / `:mapleader` | いまの付け替えを表示。リーダーの初期値は Space。変えるときは `:mapleader ,` |
| `:settings` | `settings.json` を nvim（無ければメモ帳）で開く。閉じたら読み直す。壊れていたら今の設定のまま |
| `:set paste shift+insert` | いまの前面アプリの貼り付けキー。`ctrl+v` / `ctrl+shift+v` / `shift+insert` など |
| `:set a="{{date}}"` | 変数。値は書いたまま。`{{var:a}}` で貼るとき展開。`:set` だけで一覧。`:set a=` で消す。`paste` は名前にできない |
| `:n 100` | `{{n}}` の初期値。`settings.json` に残る。`:n` だけでいまの値。`:n 1` で 1 から。`{{n:2}}` の `2` は桁 |
| `:tags` | いまの一覧のタグと件数 |

| `j` / `k` | 範囲を伸ばす |

## 並び順とタグ

一覧はピン留め（`+` / `-` の手動順）、その下は新しい順。貼った回数や貼り付け先では並べ替えない。

`Ctrl+4` で登録するとき、`http://` `https://` で始まれば `#url`、`C:\...` や `/...` のようなパスなら `#path` が自動で付く。`#run` は自動では付かない。

| タグ | 動き |
| --- | --- |
| `#pin` 相当 | `gp` で付ける。先頭に固定 |
| `#secret` | 一覧の本文を `••••`。貼り付けは普通 |
| `#tmp` | 次回起動時に消す |
| `#alias:foo` | `/foo` でも当たる。`{{@foo}}` でその本文 |
| `#run` | 貼るときコマンドを実行 |
| `#file` | 本文のパスのファイル内容を貼る |
| `#once` | 貼って成功したら消す |
| `#app:chrome` | 前面のアプリ名が `chrome` のときだけ出す。`#app:code` と複数ならどれか。ブラウザはページが違っても当たる。名前は実行ファイル（拡張子なし） |
| `#not:chrome` | そのアプリのときは出さない。`#app:` と両方なら、アプリに当たって `#not` に当たらないときだけ |
| `#ttl:1h` | 登録からその時間が過ぎていたら起動時に消す。`m` / `h` / `d` だけ。パースできなければ残す |
| `#tsv` | 貼るときタブ区切りにする。自動では付けない |
| `#log:path` | 前面へ貼らずファイルへ追記。パスに空白は使えない |

貼り付け先は前面アプリの実行ファイル名で覚える。ブラウザ（chrome / msedge / firefox / brave / vivaldi / opera / chromium / zen）はウィンドウタイトルから取ったページ名まで見るので、ページごとに履歴が分かれる。URL は読まない。

## 実行時ランタイムが無いとき

[WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) を入れる。Windows 10/11 には大体入っている。
