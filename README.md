# hataclip

Windows / Ubuntu 向けのテキスト専用クリップボードピッカー。常時監視はしない。

ホストに入れるのは **Docker だけ**。Rust / Node の開発パッケージは不要。成果物は Windows の `exe` と Ubuntu のバイナリ。

## clone 直後のビルド

```bash
git clone <this-repo>
cd hataclip-tauri
docker compose run --rm test
docker compose run --rm windows-build
docker compose run --rm linux-build
```

Windows（PowerShell 7）:

```powershell
git clone <this-repo>
cd hataclip-tauri
./scripts/test.ps1
./scripts/build-windows.ps1
```

初回はイメージの構築で時間がかかる。

`node_modules` と `.svelte-kit`、`src-tauri/target` は Docker のボリュームに置く。バインドマウント越しの書き込みが遅いため。ホスト側にこれらは増えないので、作り直したいときはボリュームを消す:

```bash
docker compose down -v
```

## 成果物

- Windows: `dist/windows/hataclip-gui.exe`（トレイ）と `dist/windows/hataclip.exe`（パイプ）、同じフォルダの `WebView2Loader.dll` / `libgcc_s_seh-1.dll` / `libstdc++-6.dll` / `libwinpthread-1.dll`
- Ubuntu: `dist/linux/hataclip`

インストーラ（`.msi` など）は出さない。

## 実行

Windows は `dist/windows` ごとコピーしてから:

```powershell
.\dist\windows\hataclip-gui.exe
```

Ubuntu は:

```bash
./dist/linux/hataclip
```

式を1つ渡すと、ウィンドウを開かずにそのパイプを実行して終わる。標準入力がパイプならそれが流れの最初。行き先が無ければ標準出力。`hataclip quote` は引用符付きで画面に出す。`hataclip "quote \"> \" | clip"` はクリップボードへ書く。`hataclip add` は標準入力を一覧へ1件足す。`hataclip clip` は標準入力をクリップボードへ書く。一覧は `items.json` が新しければ読み直す。開いているあいだも同じで、そのあと一覧を変えても足した行は残る。`hataclip "echo 3+4"` は `7`。壊れた段や空の入力は何も出さず終了コード 1。引数が無く、標準入力もパイプでなければ一覧を出す。Windows は exe を分ける。トレイは `hataclip-gui.exe`（コンソールなし。ダブルクリックで常駐）。パイプは `hataclip.exe`（コンソール付き。毎回打つ名前は短くする）。例: `dir | .\dist\windows\hataclip.exe "quote | clip"`、`.\dist\windows\hataclip.exe "echo 3+4"` は `7`。式が無い、または2つ以上なら終了コード 1。Linux は `hataclip` 1本でトレイもパイプも行う。

実行時は `libwebkit2gtk-4.1-0` と AppIndicator（`libayatana-appindicator3-1`）が要る。

起動後はトレイに常駐する。ショートカットでも出す。トレイの右クリックから設定と終了。

- `Ctrl+4` 前面の選択を登録（選択が無ければクリップボード）。登録後クリップボードは元に戻る。同じ本文は先頭へ移すだけで、2件目は作らない。Ubuntu ではクリップボードだけ
- `Ctrl+7` ドロップダウンを表示。前回選んでいた行があればそこを選ぶ
- `Ctrl+8` 空白を除いた先頭が `/` なら履歴の補完（`/` は検索語に入れない。`/foo` は `foo`。`/` だけは何もしない）。選択が空なら `Shift+Home` で行頭まで選び、行に `/` があれば最後の `/` から行末だけ補完して前は残す。改行があれば何もしない。それ以外は前面で選んだ `{{date}}` / `:sh dir` / `:echo 2+3` を置き換えて貼る。`:sh` `{{sh:}}` `:@` は実行前に確認する。1行で `sh` か `echo` が結果を作るなら後ろの段も掛ける（`:sh dir | quote`。シェルの `|` は `:sh "dir | sort"`。知らない段は何もしない）。2行以上で1行目が `:` のパイプなら、その式を2行目以降に実行して選択全体を置き換える（`:s/old/new` の次の行の `old` を `new` に。`:quote | upper` なら `> XXX`。1行目が `:echo` だけなら何もしない）。1行目が `log` なら2行目以降を `defaultLogFileName` へ足す。選択は置き換えない。未定義なら何もしない。入力が要る1行は何もしない。展開結果が空、またはクリップボードに置けなければ、選択もクリップボードも変えない。コピーが失敗してクリップボードが変わらなければ何もしない。一覧は出さない。Ubuntu ではクリップボード上のテキストを対象にする
- `Ctrl+9` 前面の選択語で履歴を補完し、一覧の Enter と同じく展開して貼る（`/` と同じ当たり。`#secret` は除く）。`{{date}}` は日付。`{{ask:}}` や `{{pick:}}`、`#run` `#confirm` `#grab`、本文がパイプの行は何もしない。当たりは一覧の `/` と同じ（`#work` はタグ、`#work hello` はタグと本文、`#alias:x` と `#alias:y` なら `x y` でも当たる。`#` だけは何もしない）。2秒以内の連打は、次が展開して空でなければ `Ctrl+Z` のあと次の候補。次が無い、空、対象外なら `Ctrl+Z` しない。当たらなければ何もしない。Ubuntu は展開した文字をクリップボードへ置く。置けなければ変えない
- `Ctrl+Shift+1`〜`9` 一覧を出さずに貼る。`#slot:3` があればその行（複数ならいまの並びの先）。無ければ今までの番号（設定の「速貼」で on/off）。本文がパイプならそのパイプを実行する。`#slot:1` が `:sel | snake` なら、前面の `getUserName` は `get_user_name` になる。段が不正か選択が空なら何もしない
- トレイを左クリックしてもドロップダウンを表示

Ubuntu（Wayland）では他アプリへキーを送れない。`Enter` はクリップボードに置いて一覧を閉じる。自分で貼る。クリップボードは戻さない。`:type` / `{{type:}}` / `{{sel}}` / `#app:` / `{{app}}` / `{{front}}` / `a` / `ga` / `target_keys` は動かない。グローバルショートカットは compositor 次第。取れなければトレイから出す。

`Ctrl+4` と `Ctrl+7` と展開はトレイの `Settings` から変更できる。展開のキーが補完もする。設定は `settings.json` に残る。位置とサイズもここに残る。ほかのアプリに取られているキーは登録に失敗して、元のキーに戻る。

前面アプリへ送るコピー／貼り付けは、初期値 `ctrl+c` / `ctrl+v`。プロセス名ごとに変えるときは `target_keys` に書く。`:settings` でファイルを開く。`:set copy ctrl+shift+c` は、いま前面にあるアプリのコピーだけ書く。`:set paste shift+insert` は貼り付けだけ書く。一覧を開くときはコピーキーを送らない。`Ctrl+4` と、実行するときの `sel` はそのキーを送る。

```json
"target_keys": {
  "putty": { "copy": "ctrl+insert", "paste": "shift+insert" },
  "windowsterminal": { "copy": "ctrl+shift+c", "paste": "ctrl+shift+v" }
}
```

## キー操作

一覧の中で `:help`。機能ごとなら `:help sh`。`{{date}}` などのトークンは `:help template`。

### 移動

| キー | 動き |
| --- | --- |
| `j` / `k`、`↓` / `↑` | 移動。先頭と末尾で止まる |
| `gg` / `G` | 先頭 / 末尾へ |
| `/` | 検索。本文の先頭 4KB だけ照合する。IME で日本語変換してから絞る（`tokyo` では `東京` に当たらない） |
| `Ctrl+N` / `Ctrl+P` | 検索中でも移動 |
| `Tab` / `Shift+Tab` | 通常はよく使うタグで絞り込みを切り替える。検索中は一覧へ（絞りと検索欄は残る）。`#` の候補があるときはタグ補完 |
| `a` | いまの貼り付け先に記録がある行だけ。もう一度で解除 |
| `f` のあと 1 文字 | その文字で始まる行へ。`;` 次、`,` 前 |
| `Ctrl+D` / `Ctrl+U` | 半ページ下 / 上。端で止まる |
| `g` のあと `e` | 選択行を展開して全文。`{{sh:}}` はここで実行する（2秒・1000行・100KBで打ち切り）。もう一度で閉じる |
| `g` のあと `?` | 貼り付け先・タグ。もう一度で閉じる。`j` / `k` で行が変わればその行の情報 |
| `Esc` / `Ctrl+[` | 検索の絞りを外す。絞りが無ければ閉じる。選択中なら選択だけ解除。ヘルプ中はヘルプだけ閉じる。`g` 待ちのときは待ちだけ解除 |

`g` / `d` / `y` / `f` / `<leader>` のあと 400ms キーが無ければ、次に押せるキーを一覧の下に出す。出る前に次のキーを押せば出さない。

### 貼り付け・コピー

| キー | 動き |
| --- | --- |
| `Enter` | 貼り付けて閉じる。次に一覧を出すとその行 |
| `Ctrl+Enter` | 貼り付けて一覧を残す（続けて貼れる） |
| `1`〜`9` | その番号の行を貼り付けて閉じる |
| `Ctrl+1`〜`9` | その番号の行を貼り付けて残す |
| `:format` | 整形して貼り付ける。`:format | clip` ならクリップボードへ |
| `:raw` | テンプレートも `#run` も通さず本文のまま貼る |
| `:join` | 選択行を区切りで 1 行にして貼る。未指定は `,`。タブは `:join "\\t"`。1 行ならその本文。`V` ならその範囲。`:comma` と `:tab` は何もしない |
| `:quote` | 各行の端に付ける。未指定は行頭の `> `。空白は `:quote "* "`。行末も `:quote "> " "<"` で `hello` が `> hello<`。`""` はその端を付けない。すでに同じ印なら重ねない。空行にも付ける。履歴は触らない。`:quote | clip` 可。末尾の `> clip` は何もしない |
| `:type` | `Ctrl+V` ではなく 1 文字ずつ送る。履歴のタグは触らない |
| `:open` | URL ならブラウザ、パスなら Explorer（Ubuntu は `xdg-open`） |
| `:log` | 選択行をファイルへ追記する。前面には貼らない。未指定は変数 `defaultLogFileName`。未定義なら何もしない。`:log path` でそのファイル。既存の改行に合わせ、無いファイルは CRLF。`| log` も同じ。`:echo 3+4 | log` は前面に貼らない。Ctrl+8 で1行目が `log` なら続く行を足し、選択は置き換えない |
| `g.` | 直前に貼った行をもう一度。失敗したとき・終了後は何もしない |
| `Ctrl+C` | 展開してクリップボードへ。`{{sh: dir}}` も実行する。履歴の本文は書き換えない |

`:format` の整形は、行頭の `>` を外す、前後の空白を落とす、連続した空行を 1 つにまとめる、全体を囲む `"` `'` `「」` を外す。中のインデントは残す。欲しければ `:map` で昔のキーを付けられる。

貼ったあとは、元のクリップボード（テキストのときだけ）を 200ms 後に戻す。

本文のプレースホルダは貼る直前だけ置き換わる。履歴の本文は書き換わらない。

| トークン | 中身 |
| --- | --- |
| `{{date}}` | `2026/09/20` |
| `{{time}}` | `10:54` |
| `{{date:%Y%m%d}}` / `{{date %Y%m%d}}` | chrono の strftime |
| `{{date-1d}}` / `{{date-1d:%Y%m%d}}` | 昨日。`{{date+2d}}` `{{date+1w}}` `{{date+1m}}` も可 |
| `{{clip}}` | いまのクリップボード。空なら空 |
| `{{sel}}` | 前面の選択。`Ctrl+C` の 200ms 後。クリップボードが変わらなければ空。`{{sel|clip}}` は空なら隣。隣がトークンならそれを展開し、違う文字ならそのまま。`{{front|無題}}` `{{sel|clip|なし}}` |
| `{{ask:名前}}` | 貼る前に入力。同じ名前は 1 回 |
| `{{pick list: prod, stg, dev}}` | 貼る前に候補から選ぶ。`j` / `k` と Enter。候補が 9 個までなら `1`〜`9`。`{{pick: prod, stg}}` は空。`{{pick tag:env}}` はタグの本文。`{{pick search: "xx"}}` は `/` と同じ当たりの行（自分自身は入れない。無ければ聞かない） |
| `{{app}}` / `{{front}}` / `{{focus}}` | 前面アプリのプロセス名 / ウィンドウタイトル / 入力欄の種類（`Edit` `Document` `ComboBox`）。無ければ空。Ubuntu の `{{focus}}` は空 |
| `{{when app: chrome}}` / `{{when var: a: "AAA"}}` / `{{when focus: Edit}}` / `{{when}}` | 先に当たった枝だけ残す。アプリは複数可（`chrome, msedge`）。変数は `:set` のそのままの文字列。フォーカスは `Edit` `Document` `ComboBox`。どれにも当たらなければ `{{when}}`、それも無ければ空。`{{when chrome}}` は展開せずそのまま。Ubuntu では app と focus は空 |
| `{{n}}` / `{{n:2}}` | 連番。`Ctrl+Enter` で増える。`:n 100` で初期値。閉じると初期値に戻る。`ge` や `Ctrl+C` では進まない |
| `{{uuid}}` | UUID v4 |
| `{{user}}` / `{{host}}` | ログイン名 / コンピュータ名 |
| `{{env:USERPROFILE}}` | 同名の環境変数。無ければ空 |
| `{{var:a}}` / `{{var a}}` | `:set a=` の値。書いたまま残して、貼るとき展開。中の `{{date}}` も展開する。値が `:sh dir` ならそのとき実行。`:set` では実行しない。`:` はエクスプローラーの名前に使えないので空白でもよい。名前に `{{var:b}}` を書ける（`{{var: {{var: b}}}}`） |
| `{{tag:work}}` / `{{tag work}}` | いまの一覧でタグ `work` の本文。並びどおり、改行つなぎ。差し込んだ本文も展開する。同じタグを二度辿ったら空。その行の `#run` などは見ない |
| `{{type:<Tab>}}` / `{{type <Tab>}}` | 貼る途中でキーを送る。`id{{type:<Tab>}}pass` は `id` を貼って Tab を押して `pass` を貼る。`{{type:<Ctrl+A>abc<Tab><Ctrl+A>def<Enter>}}` も可。矢印は `<Up>` `<Down>` `<Left>` `<Right>`。F キーは `<F1>`〜`<F24>`。`<Ctrl+Shift+A>` のように修飾キーを重ねられる。`<...>` の外の文字は 1 文字ずつ送る。`Tab` `Enter`/`CR` `Esc` `Space` `BS` `Del` `Home` `End` `PgUp` `PgDn` |
| `{{wait:200}}` / `{{wait 200}}` | そのあと 200ms 待つ。最大 5 秒 |
| `{{sh: コマンド}}` | `#run` 付きの行だけ実行。標準出力。失敗したら貼らない |

`#run` 付きで `{{sh:}}` が無ければ、本文全体を PowerShell として実行する。貼る前に標準出力を出して、Enter で貼る・Esc で中止。`#confirm` は展開後を同じ画面で出す（`#run` があればそれで足りる）。`#file` は本文をパスと見てファイル内容を貼る（`#run` が優先）。`:type` は `Ctrl+V` ではなく 1 文字ずつ送る。

`:` の代わりに空白でも同じ。`{{var a}}` `{{env USERPROFILE}}` `{{date %Y%m%d}}` `{{sh echo hi}}` `{{tag work}}` `{{type <Tab>}}`。エクスプローラーの名前変更では `:` が使えない。

`Ctrl+4` と `Ctrl+7` は全体のショートカットが先に取るので、一覧内の `Ctrl+4` / `Ctrl+7` では貼れない。

### 編集・整理

| キー | 動き |
| --- | --- |
| `dd` | 削除。`#lock` は残す。`p` / `P` で戻せる |
| `u` | 直前の `dd` を取り消す（1 段だけ） |
| `yy` / `Y` | ヤンク |
| `p` / `P` | ヤンクしたものを下 / 上に置く |
| `o` / `O` | いまの行の下 / 上に空行を作って編集。ピンの隣ならピン。`Esc` はその行を捨てる |
| フォーカス | 一覧から離れると隠れる。編集、`:`、問い合わせ、ヘルプ、タグのあいだは残る |
| `S` | 本文を改行で分割して複数行にする |
| `J` | `V` 中なら選んだ行を改行で 1 行にまとめる。タグは和集合。ピンはどれかにあれば残す。`#lock` があるとまとめない。`S` の逆 |
| `c` | すぐ下に複製（新しい id）。`V` 中は範囲ごと |
| `e` | その場編集（`Ctrl+Enter` 保存、`Esc` 取り消し） |
| `E` | nvim（無ければ `$EDITOR`、それも無ければメモ帳）で編集。閉じると読み戻す |
| `t` / `T` | タグを付ける / 外す |
| `gp` | ピン留めを切り替える |
| `ga` | 選んだ行の `#app:` をいまの前面アプリにする。ほかの `#app:` は外す |
| `+` / `-` | 1 つ上 / 下へ。ピン同士、ピンでない行同士。塊をまたがない。`#lock` でも動く |
| `Ctrl+;` / `Ctrl+-` | 一覧全体の文字を 1px 大きく / 小さく。9〜32。`settings.json` に残る。`;` だけは検索の次 |
| `u` / `Ctrl+R` | 直前の 1 回を取り消す / やり直す。もう一度 `u` しても、それより前には戻らない |
| `.` | 直前の変更をもう一度 |
| `:` | コマンド。`Tab` / `Shift+Tab` でコマンド名を補完。入力欄で一覧が短くなっても選択行（`V` なら範囲の先頭）は見える |

`.` が覚えるのは `dd`・`p` / `P`・`t` / `T`・`gp`・`ga`・`S`・`J`・`c`・`:s`・`:sort`・`:!!`・`g~`・`g:`・`+` / `-` だけ。`g~` は `#grab` の1行目と2行目を入れ替える。移動やヤンク、貼り付けは覚えない。アプリを終了すると忘れる。

ファイルを一覧へドロップすると、パスを本文にして `#path` と `#file` を付けた行を先頭に作る。フォルダでもよい。常時監視はしない。

`:` のあと:

| コマンド | 動き |
| --- | --- |
| `:help` / `:help sh` / `:help template` | 使い方。`j` / `k` でスクロール。`{{date}}` などの一覧は `template` |
| `:showerror` | 直前の失敗を1つ出す。成功すると消える |
| `:sh dir` | 1 行実行して標準出力を貼る。履歴には残さない。stdin なし |
| `:.!sh xxx` | カレント行（`V` なら改行つなぎ）を stdin に流して `xxx` を実行。標準出力を貼る |
| `:!!sh xxx` | カレント行（`V` なら各行ごと）を stdin に流し、標準出力で本文を書き換える。貼らない。式が残る。`g:` でもう一度。失敗したらそのまま。`.` の対象。`u` で戻せる |
| `:@` | 直前の `:sh` / `:.!sh` のスクリプトをもう一度（stdin はいまの選択） |
| パイプ | `:` の入力中は結果を出さない。`Ctrl+Enter` で先頭12行を出す（`sh` と `sel` は出さない。式を書き換えたら消える。一覧は隠さない）。左から `\|` でつなぐ（`:sh dir \| sh sort \| quote "x " \| clip`）。一覧の最初の `:sh` は stdin なし。次の `:sh` は左の結果を stdin に受け取る。Ctrl+8 の複数行では1行目の `:sh` が下の行を stdin に受け取る。1行で `sh` か `echo` が自分で結果を作るパイプも実行する（`:sh dir | quote`。シェルの `|` は引用符の中）。`filter ".txt"` は含む行だけ。`filter not ".txt"` は除く。当たらなければ何もしない。`"` の中の `\|` では切らない。行き先は末尾の1つ。`clip` はクリップボード（前面には貼らない。末尾の `> clip` は何もしない。流れの途中ならその文字を書いて同じ文字を次へ渡す。空なら変えない）。`add` は一覧へ1件（改行は残す。`Ctrl+4` と同じ自動タグ。クリップボードは触らない。式が残り、`g:` でもう一度実行できる。`:from` で式だけ編集。途中の `add` は同じ文字を次へ渡す。空や流れが無い途中の `add` は足さない）。`set a` は変数へ残す。`open` は URL かパスなら開く。`show` はヘルプ画面に出す。`log` は変数 `defaultLogFileName` へ追記する（`:echo 3+4 | log`。`| log path` でそのファイル。未定義なら何もしない。前面には貼らない）。行き先が無ければ前面へ貼る。先頭の `.` は選択行（`V` は改行つなぎ。展開しない）。先頭の `clip` はクリップボードを読む。`sel` は前面の選択（Windows は `Ctrl+C` の 200ms 後を読んで、すぐ戻す。空なら何もしない。Ubuntu では履歴の行の `sel` は実行しない。Ctrl+8 の複数行では実行し、結果はクリップボードへ置く）。流れがあるあとの `clip` は不正で何もしない。`camel` `pascal` `snake` `kebab` は名前を区切って組み直す。`upper` `lower` は文字だけ変える。`json` `xml` は整形する。読めなければ何もしない。`split` は区切り必須（タブは `split "\\t"`）で、列をタブでつなぎ直す。`col 2` は 2 列目（足りない行は捨てる）。`get /a/0` は JSON Pointer。文字列は引用符なし。`diff .` と `only clip` は行を比べる。引数は `.` か `clip`。共通行は出さない。全部同じなら何もしない。`put /n 2` は JSON のその位置を書き換える。読めない、またはポインタが無いときは何もしない。`each` より後ろは行ごとに実行し、成功した行だけをつなぐ。後ろに `sh` があると何もしない。`echo` は式の結果で流れを置き換える（左は見ない。計算できなければ何もしない）。段が 1 つでも同じ（`:upper` は選択行を大文字にして貼る） |
| `:export <path>` | 履歴を Markdown に書く |
| `:import <path>` | その Markdown を読み戻す |
| `:quote` | 各行先頭に付ける。未指定は `> `。`:quote "* "` は箇条書き |
| `:join` | `V` 中なら区切りでつないで貼る。未指定は `,`。タブは `:join "\\t"` |
| `:format` | 整形して貼る |
| `:raw` | 本文のまま貼る |
| `:open` | URL ならブラウザ、パスなら Explorer（Ubuntu は `xdg-open`） |
| `:log` | 選択行をファイルへ追記する。前面には貼らない。未指定は変数 `defaultLogFileName`。未定義なら何もしない。`:log path` でそのファイル。既存の改行に合わせ、無いファイルは CRLF。`| log` も同じ。`:echo 3+4 | log` は前面に貼らない。Ctrl+8 で1行目が `log` なら続く行を足し、選択は置き換えない |
| `:type` | `Ctrl+V` ではなく 1 文字ずつ送る。履歴のタグは触らない |
| `:echo 2+3` | 四則演算の結果を貼る。`*` `/` が先。`()` で変えられる。`:set a=2` の変数も使える。失敗したら貼らない。パイプの段にもでき、`:echo 3+4 \| show` はヘルプ画面に出す |
| `:s/old/new` | 選択行の `old` を全部 `new` にして前面へ貼る。履歴は触らない。正規表現は使わない。`old` が空なら何もしない。結果が空でも選択は空。段は `:sel \| s/old/new` |
| `:sort` | `V` 中なら選んだ行を本文の順に並べ替える。ピンとタグはそのまま。範囲の先頭の位置から置く。`.` の対象。`u` で戻せる |
| `:clear` のあと `:clear yes` | ピン留めと `#lock` 以外を消す |
| `:dedup` のあと `:dedup yes` | 空白と改行だけ違う行を 1 つに。ピンがある方、どちらもピンなら新しい方。`u` で戻せる |
| `:map lhs rhs` | 通常モードのキーを付け替える。再帰しない。`:map <leader>* :quote "* "` のように書ける |
| `:unmap lhs` | 付け替えを消す |
| `:map` / `:mapleader` | いまの付け替えを表示。リーダーの初期値は Space。変えるときは `:mapleader ,` |
| `:settings` | `settings.json` を nvim（無ければメモ帳）で開く。閉じたら読み直す。壊れていたら今の設定のまま |
| `:set copy ctrl+shift+c` | いまの前面アプリのコピーキー。`ctrl+c` / `ctrl+shift+c` / `ctrl+insert` など。`Ctrl+4` と実行時の `sel` が送る。一覧を開くときは送らない |
| `:set paste shift+insert` | いまの前面アプリの貼り付けキー。`ctrl+v` / `ctrl+shift+v` / `shift+insert` など |
| `:set a="{{date}}"` | 変数。値は書いたまま。`\"` は `"`、`\t` はタブ、`\n` は改行。`{{var:a}}` で貼るとき展開。`:set` だけで一覧。`:set a=` で消す。`paste` と `copy` は名前にできない。`:set a+=1` は貼って成功したあと 1 増やす。無い変数は 1。数字以外には付かない。`:set a=100` は数を変えて、増やす印は残す |
| `:n 100` | `{{n}}` の初期値。`settings.json` に残る。`:n` だけでいまの値。`:n 1` で 1 から。`{{n:2}}` の `2` は桁 |
| `:tags` | いまの一覧のタグと件数 |

| キー | 動き |
| --- | --- |
| `V` | 選択の開始・解除 |
| `j` / `k` | 範囲を伸ばす |
| `Enter` | 選んだ行を改行でつないで貼り付け |

| `:join` | カンマなど指定した区切りでつないで貼る |

## 並び順とタグ

一覧はピン留め（`+` / `-` の手動順）、その下は新しい順。貼り付け先では並べ替えない。

`Ctrl+4` で登録するとき、`http://` `https://` で始まれば `#url`、`C:\...` や `/...` のようなパスなら `#path` が自動で付く。`#run` は自動では付かない。

| タグ | 動き |
| --- | --- |
| `#pin` 相当 | `gp` で付ける。先頭に固定 |
| `#secret` | 一覧の本文を `••••`。貼り付けは普通 |
| `#alias:foo` | `/foo` でも当たる。`#alias:x` と `#alias:y` なら `x y` でも当たる。順は問わない |
| `#run` | 貼るときコマンドを実行 |
| `#confirm` | 貼る前に展開後を出して Enter。`#run` があればそれで足りる |
| `#slot:3` | `Ctrl+Shift+3` でその行。複数なら一覧の先。無ければ今までの 3 番目 |
| `#grab` | 1行目が型、2行目が出力。穴は `<org>` のように書く。選択が型に当たれば2行目を埋めて貼る。当たらなければ何もしない。Ubuntu はクリップボードを照合する |
| `#file` | 本文のパスのファイル内容を貼る |
| `#lock` | `dd` / `:clear` / `J` で消えない。外すのは `T` |
| `#app:chrome` | 前面のアプリ名が `chrome` のときだけ出す。`#app:code` と複数ならどれか。ブラウザはページが違っても当たる。名前は実行ファイル（拡張子なし） |
| `#not:chrome` | そのアプリのときは出さない。`#app:` と両方なら、アプリに当たって `#not` に当たらないときだけ |

貼り付け先は前面アプリの実行ファイル名で覚える。ブラウザ（chrome / msedge / firefox / brave / vivaldi / opera / chromium / zen）はウィンドウタイトルから取ったページ名まで見るので、ページごとに履歴が分かれる。URL は読まない。

## 実行時ランタイムが無いとき

[WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) を入れる。Windows 10/11 には大体入っている。
